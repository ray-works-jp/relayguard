RelayGuard（ローカル版）— はじめにお読みください（README-ja.txt）

■ 起動
  フォルダ内の RelayGuard.exe をダブルクリックしてください。
  黒い画面が開き、数秒後にブラウザでRelayGuardが開きます。
  ブラウザが開かないときは、黒い画面に表示された http://127.0.0.1:.../login?token=... を開いてください。

■ 終了
  黒い画面を閉じると終了します。案件はメモリ上だけに保持され、終了すると消えます。

■ 初回の警告について
  署名のない配布物のため、Windowsが「WindowsによってPCが保護されました」と表示することがあります。
  入手元を確認したうえで「詳細情報」→「実行」を選んでください。

■ できること / しないこと
  ・英文メールの解釈 → 日本語で承認 → 承認内容だけの英語返信 → 検査 → 最終承認 → コピー
  ・メールを送信する機能はありません。コピーした本文をご自身のメールソフトで送ってください。
  ・「検査を通過」は安全の保証ではありません。送信内容の責任は利用者にあります。

■ まず試す
  案件がないときのトップ画面にある「サンプル案件を開いて試す」を押すと、架空の返金依頼メールで
  一通りの流れを試せます（APIキー不要・外部送信なし）。

■ Claudeにメールを読み取らせる（英語を読まずに進める方法）
  1. Anthropic Console（https://console.anthropic.com/）でAPIキーを作ります（sk-ant- で始まる文字列）。
     API の料金はご自身のアカウントに請求されます。Claude Pro/Max の契約とは別会計です。
  2. トップ画面の「＋ 新しいメールを解析」を押し、「まず APIキーを設定」の欄にキーを貼り付けます。
     説明を読み、「上の内容に同意する」にチェックして「設定する」を押します（上部の「設定」からも設定できます）。
     送信への同意はこのときの1回だけで、メールごとには確認しません。
  3. 英語のメール本文を貼り付けて（または .eml ファイルから読み込んで）「解析する」を押します。
  ・キーはこのPCのメモリにだけ置き、ファイルには保存しません。RelayGuard を終了すると消えるので、
    次回起動したときにもう一度入れてください。
  ・RelayGuard 自体はキーを保存しませんが、ブラウザがパスワードとして保存を提案する場合があります。
    「保存しない」を選んでください。保存してしまった場合は、ブラウザのパスワード管理画面から削除してください。
  ・キーを設定しただけ、.eml を読み込んだだけでは何も送信しません。「解析する」を押したメールの件名と本文だけが
    Anthropic に送られます。メールには相手の氏名や連絡先も含まれることにご注意ください。
  ・長いメールでは読み取りに最大5分かかります。
  ・APIキーを使わない場合は「手動で登録」タブが使えます（英語の原文を読む必要があります・外部送信なし）。
