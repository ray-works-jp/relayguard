まず APIキーを設定

APIキーはこのPCのメモリだけ ／ 解析するメールの本文を Anthropic へ送信 ／ API料金が発生

詳細
  • キーはファイルにも記録にも残さず、RelayGuard を閉じると消えます。次回はもう一度入れてください。
  • 送信されるのは「解析する」を押したメールの件名と本文だけです。作者や他の場所には送りません。
  • 料金はあなたの Anthropic API 契約に請求されます。キーは Anthropic Console で作れます。

RelayGuard 自体はキーを保存しません。ただし、ブラウザがパスワードとして保存を提案する場合があります。「保存しない」を選んでください。保存してしまった場合は、ブラウザのパスワード管理画面から削除してください。
