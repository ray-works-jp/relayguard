## RelayGuard 初期版 — 英語メールの返信案を、自分が承認した内容だけで作る Windows 用ツール

英語のメールに返信するとき、翻訳AIの英文に「返金します」「保証します」「明日までに対応します」が紛れ込んでも、英語が読めないと気づけません。

RelayGuard では、返信に入れる内容を**日本語の画面で1項目ずつ決めます**。英語の返信案は、決めた内容だけから組み立てます。返信案を別の仕組みで読み直し、**決めていない金額・日付・約束・保証・返金・リンクが1語でも入っていたら止めます**。

### 使い方の流れ

1. 英語メールを取り込む（`.eml` ファイル、または本文の貼り付け）
2. メールの中身（質問・金額・期限・求められている約束）を登録する
   - 自分で原文から選んで登録する（APIキー不要・外部送信なし）
   - または、ご自身の Anthropic APIキーで Claude に下書きさせる（任意）
3. 日本語の画面で、項目ごとに「承認する／保留／回答しない」を選び、質問への回答を書く
4. 承認した内容だけから英語の返信案を作り、検査する
5. 検査を通った版を確認して承認し、コピーしてご自身のメールソフトで送る

### 特徴

- **メールを送信しません。** 最終的に送るのはあなたです。（Claude による下書きを使う場合は、「解析する」を押したメールの件名と本文が Anthropic 社の API に送られます）
- **返信案の各行に、誰の意図かを表示します。** 定型文／あなたが書いた文／あなたが承認した内容を機械が組み立てた文、のどれかです。どれにも当たらない行があると止まります。
- **判定はプログラムが行います。** AI（Claude）は任意の下書きにだけ使い、原文の一字一句の引用がない下書きは採用しません。
- **法的な主張・AIへの指示文・添付ファイルへの依存を含むメールは、返信案を作らずに止めます。**
- **このPCの中で動きます。** メール本文を保存しません（終了すると消えます）。記録に残るのは ID と hash だけです。

### できないこと（初期版の制限）

- 返信の英文は定型の構成です。自然な言い回しの作文はしません。
- 英語メール → 英語の返信のみです。添付ファイルの中身は読みません。
- 文章の「意味」までは検証しません。検査するのは「承認した行だけでできているか」と、金額・日付・数量などの値の一致です。
- 作業中の案件は保存されません。終了や異常終了で消えます。
- Windows 専用です。コード署名がないため、初回に Windows の警告が表示されます。

### 検証の状況（正直に）

- 作者による自動テストと、合成（架空）のメールでの検証だけを行っています。
- **独立した第三者による検査、実際のメールでの評価、作者以外の利用者による試用は、まだ行っていません。** この初期版は、使っていただいた反応から直していくためのものです。
- 「検査を通過」は、内容が正しい・安全であるという保証ではありません。送る前に必ずご自身で確認してください。

### 動作環境

- Windows 〔10/11〕 64bit（作者の Windows 11 環境でのみ確認）
- Python などのインストールは不要（zip を展開して `RelayGuard.exe` を実行）
- Claude による下書きを使う場合のみ: ご自身の Anthropic APIキーとインターネット接続（API の料金はご自身の負担です）
