RelayGuard が扱うデータ（版 0.1.2）

■ 作者に送られるもの
  ありません。利用状況やメール内容を作者へ送る機能はありません。

■ 外部へ送られるもの
  Claude による読み取りを使う場合に限り、「解析する」を押したメールの件名と本文が
  Anthropic 社の API へ送られます（下記）。それ以外に、メール内容を外部へ送る機能はありません。

■ このPCの中での扱い
  ・メールの件名・本文、解釈結果、承認内容、返信案は、実行中のメモリ上にだけ置かれます。
    終了・異常終了で消えます。作業中でも24時間を過ぎた案件は削除されます。
  ・画面の表示や操作の記録（ログ）に残るのは、案件のID、hash（内容から計算した識別値）、
    判定の種類だけです。メール本文や個人情報は記録しません。
  ・.eml ファイルを読むときも、メール内の画像やリンクは読み込みません（外部へ接続しません）。
    添付ファイルは名前だけを表示し、中身は読みません。
  ・画面は、このPCの中（127.0.0.1）からしか開けません。起動のたびに発行されるURLが必要です。

■ Claude による読み取りを使う場合（任意・APIキーを設定するまでは使えません）
  ・画面で APIキーを設定するときに、送信について一度だけ同意をいただきます。
    その後は、「解析する」を押したメールの件名と本文だけが Anthropic 社の API へ送られます。
    メールごとの確認はしません。キーを設定しただけ、.eml を読み込んだだけでは送信しません。
  ・起動時に環境変数のキーを使う方法（開発者向け）では、メールごとに送信への同意を確認します。
  ・送信されたデータの扱いは Anthropic 社の規約・方針に従います。お使いになる前に、
    ご自身（またはお勤め先）のデータの取扱い条件で送ってよい内容か確認してください。
  ・画面で入れたAPIキーは、実行中のメモリにだけ置きます。ファイル・記録には残さず、画面にも再表示しません。
    終了すると消えます。キーは Anthropic 社への送信にだけ使います。
  ・ただし、ブラウザがキーをパスワードとして保存するよう提案する場合があります（RelayGuard では止められません）。
    「保存しない」を選んでください。保存してしまった場合は、ブラウザのパスワード管理画面から削除してください。

■ メールに含まれる第三者の情報
  取引相手のメールには、相手の氏名や連絡先などが含まれます。Claude による下書きを使う場合、
  それらも Anthropic 社へ送信されることにご注意ください。APIキー不要の手入力経路では外部送信は発生しません。
