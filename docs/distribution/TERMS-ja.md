RelayGuard 利用規約・免責事項（版 0.1.0 / 〔日付〕）

1. **本ソフトウェアの性質**
   RelayGuard（以下「本ソフトウェア」）は、英語メールへの返信案を、利用者が承認した内容から組み立て、承認していない内容が含まれていないかを定義済みの規則で検査する、利用者のPC上で動くツールです。メールを送信する機能はありません。

2. **利用者の責任**
   返信を送るかどうか、送る内容、送った結果についての判断と責任は、利用者にあります。送る前に、必ず利用者自身で内容を確認してください。

3. **検査の限界**
   「検査を通過」という表示は、本ソフトウェアに定義した規則に反する箇所が見つからなかったことを意味するだけで、内容の正しさ・安全性・適法性・相手方との合意内容との一致を保証するものではありません。本ソフトウェアは文章の意味を検証しません。検査の規則にも誤りや漏れがありえます。

4. **AIによる下書き（任意機能）**
   利用者が APIキーを設定して Claude による読み取りを使う場合、「解析する」を押したメールの件名と本文が Anthropic 社の API に送信されます。その扱いは Anthropic 社の規約に従います。AI の出力は誤ることがあります。API の利用料金は利用者の負担です。

5. **無保証**
   本ソフトウェアは現状のまま提供されます。特定の目的への適合性、不具合がないこと、継続して提供されることを保証しません。初期版であり、独立した第三者による検査、実際のメールでの評価は行っていません。

6. **責任の制限**
   本ソフトウェアの利用または利用できなかったことにより生じた損害について、作者は、〔故意または重大な過失がある場合を除き、〕責任を負いません。〔有償の場合の責任の上限: 利用者が支払った対価の額〕

8. **データ**
   本ソフトウェアは、メール本文を保存しません（作業中の案件はメモリ上にのみあり、終了すると消えます）。詳しくは `PRIVACY-ja.txt` をご覧ください。
