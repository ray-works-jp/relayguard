# 合成サンプル試用記録（6件）

作成: 2026-09-19 / 記録者: （あなた）

実メールが来るまでの代わりに、**同梱の合成サンプル6件**を通して記録する。
これは「実際に役に立った」の証明にはならない。証明できるのは **「この道具は本当に動き、本当に止まる」** ことだけ。
人に見せる材料としては、実メールと違って**そのまま公開できる**という利点がある。

APIキーは不要。費用はゼロ。サンプルは解釈と承認済みDecisionが最初から入っているので、
**生成 → 検査 → 最終承認 → コピー**の後半だけを通すことになる。

---

## 0. 始める前に（1回だけ）

- [ ] `RelayGuard.exe` をダブルクリックする（ブラウザが開く）
- [ ] 画面上部の「サンプル」の一覧に `RG-EVAL-xxx.input.json` が並ぶことを確認する

各件でやること（毎回同じ）:

1. サンプル名をクリックして取り込む
2. 「返信案を作成」を押す
3. 画面の判定（L0 / L1 / L2 / L3）と「次にやること」を読む
4. 止まっていなければ「最終承認」→「コピー」まで進む
5. 下の表に**見たまま**を書く

**L3 で止まる件について**: 「返信案を作成」を押した時点で停止し、返信案そのものが作られない。
画面には「L3_STOP の案件は返信生成・承認・コピーできません。手動対応へ引き継いでください。」と出る。
これは不具合ではなく、そういう設計（返信案が存在しないので、うっかりコピーすることもできない）。
